# 3KLIK — GitHub Pages

Upload **index.html**, **style.css**, and **app.js** to the root of your GitHub repository (not the containing folder).

Then enable GitHub Pages in Settings → Pages → Deploy from a branch → main → /(root).

Features: Home, Explore, Create, Stats, Profile, How it works / Risks / Terms; coin search and sorting; image upload and local browser persistence.

Important: created coins are stored in each visitor's browser, not shared between users. Wallet connection and blockchain transactions are not implemented. The site does not provide live market data. The original localStorage key is preserved so existing locally saved coins remain accessible.
